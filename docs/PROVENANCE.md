# Provenance

This repository is an additive extraction from the backed-up current modular
Battle/Star.SOL source, not a rewrite of the historical corpus.

## Primary source

Recovered source at extraction time:

```text
C:\SOL\GZG-NOW\workbench\modular-game-candidate\game\web\atlas
```

That workbench copy was hash-verified against:

```text
C:\SOL\groundzerogames\gzg\old-gzz\iterative\emergent2026\
emergent-grok-7-25-2026\game\web\atlas
```

The modular source records consolidation from the earlier Antigravity/Codex
candidate, followed by Gemini modularization notes and Grok 4.5 review. Those
reviews are evidence and analysis; the generic extraction is judged against
the canonical no-game-server, Base-10, versioned-payload architecture.

## Changes made during extraction

- moved the generic strategic surface into its own independent repository;
- froze the recovered browser-generated Tailwind rules into
  `site/atlas.generated.css`;
- removed the browser compiler from the production boot path;
- added a dedicated galaxy manifest, copied shared envelope, and A.T.L.A.S.
  payload schemas;
- normalized selection output while retaining the recovered wrapper adapter;
- bounded and validated untrusted hash-feed input;
- removed HTML interpolation from telemetry output;
- added a useful default layer set;
- corrected inherited encoding artifacts and standalone launch instructions;
  and
- added tests, documentation, licensing, and Pages automation.

## Asset notes

Three.js and OrbitControls retain their MIT attribution. The Material Icons
font is attributed under Apache-2.0.

The day, water/specular, night, and topology Earth images were already bundled
in the recovered self-contained runtime. The recovered architecture note names
their roles but not a sufficiently precise upstream URL or license record.
They are preserved here because the user owns and directed publication of the
source corpus, but this incomplete provenance remains a release limitation.
Do not replace or relabel those files without recording the new source and
license.
